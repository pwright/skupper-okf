# mq modules

`jsonschema.mq` is vendored unchanged from
[harehare/jsonschema.mq](https://github.com/harehare/jsonschema.mq/tree/cb24a6be1aaa055c4b364c7ad4cd17820361be0f)
at commit `cb24a6be1aaa055c4b364c7ad4cd17820361be0f`.
Its MIT license is included in `LICENSE.jsonschema.mq`.

The document exporter uses this local module so reporting needs no network access
or HTTP import permissions.
