## Automatic Certificate Distribution

Certificates are delivered in-band via bootstrap process or claim redemption - no out-of-band secure channel required.

### Distribution Methods

**Backbone Sites** (Bootstrap):
1. Initial bootstrap YAML contains temporary claim certificate
2. Site controller uses claim cert to connect to backbone
3. Management controller sends site certificate via in-band communication
4. Site controller applies certificate to router

**Member Sites** (Invitation):
1. Invitation YAML contains invitation claim certificate
2. Participant applies YAML to their environment
3. Site controller uses claim cert to contact management controller
4. Management controller validates claim and issues member certificate
5. Member certificate sent via in-band communication
6. Site reconfigures with member certificate

### In-band Delivery

All certificate distribution uses the data plane:

- **No out-of-band channel** - No email, manual file transfer, or secure FTP
- **No shared secrets** - Certificates are the authentication mechanism
- **Automatic delivery** - Site controllers handle the exchange
- **Encrypted transport** - TLS-secured communication via routers

### Sync Mechanism

Certificates are synchronized as TLS secrets:

**Record key:** `tls-site-<site-id>` or `tls-server-<access-point-id>`

**Payload:**
- Rotation ordinal
- Last valid ordinal
- ca.crt - CA certificate
- tls.crt - Site/access point certificate
- tls.key - Private key

**Target:** Kubernetes Secret with annotations for rotation tracking

### Contrast with Manual Distribution

**Manual approach** (VMS eliminates):
- Generate certificate on one system
- Securely transfer to another system (email, S3, shared drive)
- Manually apply certificate to destination
- Coordinate timing across sites
- Verify correct certificate installed

**VMS automatic distribution:**
- Certificate generated by management controller
- Automatically delivered via data plane
- Site controller applies to local router
- Immediate verification via heartbeat
- No manual coordination

### Security Properties

**Bootstrapping trust:**
- Initial claim certificate in bootstrap/invitation YAML
- Claim cert has restricted access (claim redemption only)
- Full certificate issued after validation
- No opportunity for man-in-the-middle during exchange

**Ongoing distribution:**
- Certificate rotation uses same in-band mechanism
- Old and new certificates valid during transition
- Seamless rotation without manual intervention
